# Contact detector model

This directory contains the quantized ONNX files used by the browser contact
detector.

- Source: `onnx-community/NeuroBERT-NER-ONNX`
- Source revision: `e3a6a290e438a506d2ba7bbb0f5875b7f034cebf`
- Source URL: https://huggingface.co/onnx-community/NeuroBERT-NER-ONNX
- Upstream model: `boltuix/NeuroBERT-NER`
- Upstream URL: https://huggingface.co/boltuix/NeuroBERT-NER
- License: Apache License 2.0; see `LICENSE` in this directory.

The ONNX model is loaded locally by Transformers.js. Remote model loading is
disabled in the application worker.
